# KunAlfaBot

Bot Telegram resmi Kun Alfa.

## Fitur
- Multi-link otomatis muncul saat pertama buka.
- AI admin/Qodam Kun Alfa, sopan, gaul, humoris.
- Jawaban dibatasi max 300 token, promosi channel resmi selalu ada.
- Memblokir video/foto berat dan spam emoji.
- Reset session 6 jam untuk pengunjung baru.
- Perintah aktif: /start, /gabung, /kontak.
- Multi-link tombol untuk semua link resmi, termasuk komunitas Telegram.

## Deploy ke Koyeb
1. Buat repository GitHub dan upload semua file.
2. Tambahkan Environment Variables di Koyeb dari `.env`.
